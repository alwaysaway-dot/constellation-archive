## 最终空间关系

保留原莫比乌斯几何、分布与运动，使用真实透视相机靠近近侧星带。选定同一材料坐标上的密集区域及两个星点，将其与第一首现有双核的屏幕投影对应。第二个材料坐标在尺寸变化时求解，避免两套透视相机交接时双核错位。

- 前段：完整环体扩大，保留中央负空间和扭转。不是放大画布或截图。
- 中段：近带扩出视口，远侧弧仍提供距离参照；第一首在对应的两个锚点附近出现。
- 后段：匹配的局部材料逐渐移交给第一首周围的航道，周边环弧退出。保留原星图终点相机、节点坐标和间距。
- 相机始终接近，没有再次拉远；姿态修正限于匹配路径切线，手机约 2.8°、桌面约 24.8°，没有追加绕行。
- 转场长度由原约 235svh 缩为 145svh；减弱动态为 45svh。所有位置由同一个原生滚动进度计算，停手不会触发独立片头，反滑沿原路径恢复。
- 标题在星象清晰后接入，进入终点前节点不可点击。菜单直接进入稳定星图；详情返回保留原纵向位置。

没有全场黑区、炸开、散点重组、重生成星河或新长链。首页和星图仍是两个现有渲染器；采用局部位置及尺度匹配后接力，没有把整环强行变形成十首作品路径。并非所有粒子保持身份一致。

减弱动态使用稳定机位和简短的局部显隐，不执行持续镜头穿行。无 WebGL 时使用同源粒子坐标的静态投影，随滚动更新构图，不宣称实时三维粒子运动。回退材质与 WebGL 的点状抗锯齿、明度有细微差别。

## 性能定位与处理

源码确认旧方案有一个额外的逐顶点过渡坐标属性，以及将未出现作品的顶点复用成另一套星河的 Shader 分支。本轮移除它们和旧时间线，不让新旧转场叠加运行。未发现两套重复的同类滚动控制器，不将用户卡顿归因于未经证实的重复循环。

首页与星图仅在进度约 0.36–1 的交接窗口共同绘制（约 0.93 个视口滚动距离）；首页端点停图，首页静止时星图停图。交接早段尚未显露的作品跳过路径纹理采样，保留编译及实际目标预热。暂停、不可见和卸载时的清理仍有效。

- 首页原主体仍为移动 11,000 / 桌面 24,000 点，仅额外加入两个锚点；4 个批量绘制调用。
- 星图移动 14,831 / 桌面 23,081 点，与旧预览总预算一致。局部材料替换原 1,400 / 2,100 个过渡点；星图最多 2 个批量绘制调用。
- 原路径纹理 53,664 字节不变；无需每帧重建几何。连续滚动与反滑期间 `geometryBuilds` 保持 1。
- 尺寸变化时只重新求解所需数据；首页第二锚点属性同步更新。不是每次滚动重新分配粒子。
- 首次实际目标预热在本次记录为约 8.9–13.2ms，发生于可见交接之前。

同一 Apple M2 / Chrome 155 / ANGLE Metal、三个视口、相同归一化操作路径，修改前后各测试：首页、首次交接、预热交接、星图滚动、停留作品、详情返回。每段 5 秒，性能采样时关闭录屏。所有场景的主线程 rAF P95 为约 16.7–16.8ms，最大约 16.8ms，>34ms 的采样间隔及 Long Task 记录均为 0。渲染提交的 CPU P95 约 0.3ms，不能当作 GPU 耗时。

**本机修改前也未复现明显卡顿，不能据此宣称已解决真实手机卡顿。** 此数据支持没有在本机观察到回归，不支持真实手机 FPS、GPU 帧耗时或掉帧率结论。归一化进度相同但新版转场距离更短，不能把这个测试当作同等物理滚动速度的完整真机比较。原始记录：`before/comparison.json`、`after/comparison.json`。

## 实际验收

- 构建、`npm run typecheck`、`git diff --check` 通过。Vite 保留 Three.js 相关约 524KB chunk 提示，无新增依赖。
- `model.test.mjs` 与 `audio-worker.test.mjs` 共 13 项通过：锚点配准、单向机位、端点、不同高度、稳定轮廓/路径、音频 Range 边界。

- `anchors.cjs`：实际 WebGL 相机矩阵的两个锚点逐阶段、反向、改变高度后均匹配；投影误差小于测试阈值 0.02 CSS px。此项验证位置计算，不代替视觉连续性判断。另存无 WebGL 与减弱动态中间态。
