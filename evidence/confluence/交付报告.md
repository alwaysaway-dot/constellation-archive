## 视觉与行为

- 桌面左侧标题保持安静，主句与次句分级；较宽曲面由左下铺入，较窄曲面从右侧折入，右下保留暗缝与前后遮挡。
- 手机采用独立路径构图，标题在上部、两片曲面在中下部交汇，入口位于首屏底部。没有新增快捷试听、封面轮播或推荐卡。
- 两片真实 Mesh 提供暗面遮挡；两组批量 LineSegments 描述形体。每帧共 4 次绘制提交，桌面 134 条线、手机 70 条线；没有后处理 bloom、新大型依赖或图片背景替代。
- 透视相机与不同 Z 深度几何实际运行。交接中宽曲面向前/侧方展开、窄曲面向后/侧方退开；诊断记录可见相反方向的 Z 位移。指针只作用于局部线束，相机不跟随鼠标大幅摇动。
- 环境信号沿局部线束短暂传递，每约 13 秒仅约 1.1 秒处于传递窗口；没有声称与音乐同步。
- 常规交接只占约 95svh 原生滚动距离；无滚动拦截和逐段吸附。中途可停、反向可恢复，点击入口到达同一终点。
- 原星图置于后方连续显露。交接结束前不可点/不可键盘聚焦；终点后原星图可滚动、聚焦和进入详情。星图在交接阶段的航行进度保持 0，节点差值限制在原细微视差范围内；没有照草图重排节点。
- 返回详情前的地图位置与已选作品保留；直接详情链接缺少历史时返回可靠星图入口。返回首页恢复完整首屏。
- 全屏菜单使用接近不透明的墨黑底；系统减少动态优先，明确显示“动态效果：完整 / 减弱”。关于入口复用已有署名及一句介绍，没有编造新页面或履历。

本轮实际修复的衔接边界：返回首页时保持观察状态对象身份，避免同一 Canvas 因对象替换被销毁后立即重建；路由切换时阻止旧滚动回调覆盖新 URL；WebKit 小数滚动终点统一到结束状态，避免已隐藏曲面继续逐帧绘制。

本地与线上预览均完成：

- 1440×900、390×844、360×740，两个浏览器各 32 项，合计每轮 192 项断言通过。

- 曲面在星图终点停止绘制，首页未显露时的星图不持续动画；离开详情路径正确卸载首页资源。

- 菜单首页、关于、其他作品导航及滚动解锁正常；桌面及窄屏关键截图无横向溢出。
- WebGL 强制不可用时，两片静态线性曲面完整显示，十首静态星图可达，可进入第十首详情。
- 完整动态正常上下滚动；站内减弱设置保留完整画面且停止常驻曲面动画。

补充检查：

- 390、360 移动触控模拟：CDP 实际分发 touchStart / touchMove / touchEnd，验证原生滚动、反向及无误入作品；单次触摸进入详情并恢复位置。

- 系统 prefers-reduced-motion 优先，菜单“完整”选项不可覆盖系统设置。

- 模拟 document.hidden 与 visibilitychange，确认帧计数停止；未把该模拟称为手机后台性能测试。

线上普通运行的页面错误、console.error、异常 HTTP 资源响应均为 0。强制关闭/丢失 WebGL 的故障注入属于单独回退测试，不混入普通运行错误统计。

## 与草图的差异、限制与待验收

1. 按文字要求明显降低内部线密度，手机比桌面更稀疏；暗缝及两片曲面的区别优先于草图中的密集织物效果。未使用参考图片作为首页背景。
2. 保留原星图的节点顺序、轨迹、相机和粒子实现；终点的节点分布以原项目为准，不复制草图的示意歌名、连线及错字。仅为连续交接调整外层视口留白与位置。
3. 常驻弯曲幅度很小，局部信号有明确安静间隔；截图展示的是稳定构图，动态以录屏和交互预览为准。没有把环境信号包装成音频分析。
4. 静态回退是同一参数形体生成的 SVG，保留轮廓、暗底、文字和入口；它不宣称拥有实时三维材质、深度缓冲或局部光学扰动。
5. 真实 iPhone Safari、实体触控板与普通鼠标滚轮的手感、动态地址栏及屏幕细线摩尔纹尚待用户真机审查。本次使用真实桌面浏览器 GPU 和模拟移动视口/触控，未测量或承诺手机 FPS，也未据此断言听觉效果。
6. 两片曲面的最终艺术观感仍需用户确认。本轮完成后停止追加设计；只有确认预览优于正式基线后，才考虑正式更新。
