## 视觉与空间行为

桌面围绕中部纵向展开，手机重新设置左右位置及标签朝向。节点是文档内的固定可点击元素，星尘通过带不同 Z 深度的透视场景绘制；相机保持受控固定姿态，纵向滚动在着色器中推进场景并产生有限层间视差。不会把纵向滚轮转成横向移动，也没有逐首吸附。

星群沿弯曲航道断续聚散，远层稀疏、中层成带、近层少量细星。滚动速度有限提升局部流动和短尾迹，停止后衰减。焦点具有稳定区，局部加强并显示现有曲风信息；其余作品仍可读。点击短转场才进一步收束选中星群、减弱周围空间，随后进入既有详情。

右下编号随当前位置变化，点击打开十首纯文字索引。索引只定位节点，不打开详情；Escape、遮罩和关闭按钮恢复滚动和焦点。详情返回保存纵向位置及选中上下文。WebGL 不可用使用同一几何采样生成静态投影，保留全部点击、索引及返回功能。

与参考图的有意差异：不复制三栏网页、不添加独立小旋涡、不按图铺满高密度背景。手机右侧节点文字向左展开，避免越界；真实视口通常显示两首及部分相邻作品，不硬凑参考板的细长比例。审美是否达到期望仍待用户比较预览。

## 已在浏览器确认

设备为 Mac Apple M2。Chrome `155.0.8059.80` 使用 ANGLE Metal Apple M2；Playwright WebKit `26.5` 使用 Apple GPU。两者均实际创建 WebGL 上下文，非静态回退冒充。

本地与已部署预览分别执行两引擎 × 三视口：1440×900、390×844、360×740。每组26项断言通过，另做两引擎强制无 WebGL 检查。

- 十首顺序与原数据一致，桌面/手机均纵向推进；轮滚前进、反向和停止正常。
- 全部标题和点击区域横向边界合格；长英文和韩文在窄屏正常换行，无横向溢出。
- 第02首浏览/聚焦/点击位置一致：三状态点击框 `(827.59,566,260,128)`。
- CDP 触摸纵滑不误开详情，一次轻触进入；第08首返回 scrollY `2605 → 2605`，焦点仍为08。
- 中段第07首和末段第10首详情返回保留位置；直接访问详情后返回有可靠默认入口。
- 键盘焦点自动定位屏外作品；索引锁滚、Escape/遮罩关闭及焦点恢复通过。
- 精选实际播放后返回星图，音频时间继续推进、仅一个 Audio 实例；迷你播放器暂停收起正常。
- 其他作品原30秒音源实际启动，抽屉保留；本轮未重做其内容和播放逻辑。
- 完整动态、站内减弱、系统减少动态优先、暂停绘制和组件释放通过。
- 首页和星图不会在各自不可见时继续无效绘制；索引展开暂停背景场景。
- 强制上下文不可用及实际 `WEBGL_lose_context` 发生后均显示静态纵向星图，可定位/进入/返回。
- 本地及预览六组运行的页面错误、控制台 error、异常资源响应记录均为空。

## 工程与性能

实际执行并通过：`npm run typecheck`、`npm run build:production`、`node --test evidence/vertical-stardust-v11/model.test.mjs scripts/audio-worker.test.mjs`（10项）、`verify.cjs`、`record.cjs`、`performance.cjs`、`edges.cjs`、线上 `verify-http.py`。

仓库没有单独 lint 脚本，未报告 lint 通过。构建仍有 Three.js 共享 chunk 大于500kB的体积提示；新增渲染模块8.63kB（gzip3.81kB），没有增加第三方依赖。预览52资源可访问，35音频Range请求与本地字节相符，7条缺失/内部路径保持404，越界Range为416。

短时采样：每视口闲置和滚动各4秒。浏览器 rAF 间隔 P95 为16.7—16.8ms，未记录大于34ms间隔或 Long Task；CPU提交P95为0.4—0.5ms。桌面4秒约241—242次绘制，手机模拟主动限制约120—121次绘制（30Hz）。点数桌面16274、移动9884，几何仅建立一次；常态1次绘制调用，活跃短尾迹最多再1次。无每帧React全量重渲染或几何重建。

这些数字是本机短时测试，不是 GPU 帧耗时，也不能视为真实 iPhone 帧率承诺。
