## 恢复方式

不使用强制重置。需要独立重建旧版时，在当前仓库执行：

```sh
git worktree add --detach ../Constellation_Afterimage_Baseline baseline/afterimage-v1-20261020
cd ../Constellation_Afterimage_Baseline
npm ci
npm run build:production
```

本轮没有修改正式站，因此不需要对正式站执行回退。只有未来正式部署需要撤回时，已保留版本可用：

```sh
npx wrangler rollback f9cc62f6-f296-48de-98f3-7787967368a9 --config wrangler.jsonc
```

仅撤回 AFTERIMAGE 展陈：将 `src/afterimage-presentation.ts` 的 `AFTERIMAGE_EXHIBITION` 改为 `false`，重新构建并发布预览。它同时撤回样板 DOM 顺序、专属样式类和简化栏目显示；来源返回修复与共用迷你播放器可见性独立保留。
